✨ Supported Features

  • HTTP/1.1 Protocol with Keep-Alive support
  • Static file serving (HTML, CSS, JS, images, binary)
  • CGI/1.1 script execution (Python, PHP, etc.)
  • File uploads via POST with size limits
  • File deletion via DELETE method
  • HTTP redirects (301, 302)
  • Custom error pages (404, 500, etc.)
  • Directory listings (autoindex)
  • Chunked transfer encoding
  • Multiple server blocks and ports
  • Virtual host support
  • Non-blocking I/O with poll()
  • Connection timeouts and limits
